# Photobooth
A Python-based virtual photobooth application built using OpenCV. The project captures photos through a webcam and recreates the experience of a real photobooth with live camera preview, countdown timers, photo capture, and image-saving functionality.

# Features
Live webcam preview
Real-time frame processing with OpenCV
Countdown timer overlay
Non-blocking photo capture system
Mirrored camera feed correction
Keyboard controls for capturing and exiting
Automatic image saving

# Technologies Used
Python
OpenCV (cv2)
NumPy

# Planned Features
Photo strips
Filters and effects
Virtual Polaroid mode
Face detection and enhancements
Custom themes and overlays
Multi-photo photobooth sessions

# Learning Objectives
This project was created as a hands-on exploration of computer vision concepts including webcam handling, image processing, real-time application loops, frame manipulation, overlays, event handling, and photo generation workflows.
